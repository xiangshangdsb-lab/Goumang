# 句芒 Goumang

面向设施农业巡检的履带式机器人。ESP32-S31-Korvo-1 负责交互、相机和 AI，STM32F407 C30D 负责履带闭环、巡线、云台和停车保护。

本仓库对应 v3.10.0，含触屏与网页履带 15%～100% 档位、540° 云台、线阵 CCD 巡线、可训练的视觉辅助和登记人员问候。

| 路径 | 内容 |
|---|---|
| [source/S31](source/S31) | 触屏、网页、相机、AI、USB 通信、语音生成工具 |
| [source/C30D](source/C30D) | 项目控制、协议、巡线和新增驱动，另含联编用 GCC 配置 |
| [接线速查](docs/接线速查.md) | C30D、S31、D36A、传感器和电机接线 |
| [巡线学习与热点联调](docs/巡线学习与热点联调.md) | 采样、训练、部署及视觉辅助生效条件 |

## 桌面仿真

在有 Python 3 和 GCC 的终端，从仓库根目录执行。

```shell
python source/S31/tests/sim/run_simulation.py
```

该仿真运行双端协议、车控和巡线核心，覆盖 100% 车控指令、急停与断链停车、540° 云台范围。

- [S31 构建、语音资源与 AI 配置](source/S31/README.md)
