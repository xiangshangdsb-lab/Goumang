# 句芒视觉与 CCD 协同巡线

S31 摄像头观察前方地面，C30D 的线性 CCD 测量车体近处的导引线。两者看到的是同一条线在不同位置的偏差。S31 利用前方画面预测约 0.2–0.35 秒后的 CCD 偏差，C30D 继续执行本地巡线与停车。模型适合固定朝前、同一安装高度和视角的摄像头。换安装位置、导引线材质或场地，应重新验证。

## 代码位置

| 位置 | 用途 |
| --- | --- |
| `source/S31/main/perception/vision.c` | 复用相机巡线采样，将下半幅图像分成 3×8 个格子。读取同一时刻的 CCD、轮速和云台遥测 |
| `source/S31/main/perception/line_learning.h` | 两层 ReLU 网络在 S31 上做本地推理，输入为 24 格暗色比例、当前 CCD 偏差和轮速 |
| `source/S31/main/perception/line_learning_weights.h` | 权重文件。随包固件为采样版，完成实车训练后才导入权重 |
| `source/S31/tools/train_line_learning.py` | 采集 JSONL，按车次拆分训练和验证，生成固件可用的 C 头文件 |
| `source/S31/main/transport/robot_link.c` | 发送巡线命令，满足条件时附带有限的视觉转向修正 |
| `source/C30D/APP/line/line_fusion.c` | 执行 CCD 与四路红外融合，核验视觉修正及前方距离 |
| `source/S31/main/network/wifi_mgr.c` | 路由器连接重试、20 秒失败回退配置热点 |

## 热点与接线

1. S31 的调试 USB 接电脑。S31 USB-A 接 C30D 的 UART3 控制通信口。C30D 刷写用 UART1/ISP。
2. 停车时在触屏打开「网络设置」。可使用同一局域网内的设备 IP，也可点「打开配置热点」并让采集电脑连接 `Goumang-S31-Setup`。热点密码和网页控制码以触屏显示为准。配置热点访问 `http://192.168.4.1`，局域网用触屏显示的 IP。热点仅用于局域网，需要 DeepSeek 时让 S31 接入有互联网的网络。
3. `/frame.bmp` 可看没有屏幕状态标签的相机画面。`/api/line-sample` 是只读采样，使用设备原有 `X-TD-Token` 控制码。采集文件记录图像格子比例、时间和车况，可在本机离线训练。

## 采集、训练和装入权重

保持镜头朝前，使用电量正常的动力电源。在封闭低速测试路线用现有 CCD 模式跑数圈，分别采集直线、左右转弯和不同光照。模型需要实际运动中的数据。S31 自动过滤停车、回退、CCD 无效及遥测过期的画面，随包采样程序以每秒最多 8 次读取样本。建议保存多份独立车次，验证路线留出单独文件。

```powershell
python source/S31/tools/train_line_learning.py record http://192.168.4.1 run-a.jsonl --seconds 90
python source/S31/tools/train_line_learning.py record http://192.168.4.1 run-b.jsonl --seconds 90
python -m pip install numpy
python source/S31/tools/train_line_learning.py train --train run-a.jsonl --test run-b.jsonl --out source/S31/main/perception/line_learning_weights.h
```

训练脚本用当前相机特征和 CCD 信息预测后续 CCD 偏差，打印验证路线上的平均绝对误差和 95 百分位误差，并与“直接沿用当前 CCD 偏差”的基线对照。如需先只看预测，可临时设 `TD_LINE_ASSIST_ENABLED=0` 重新构建 S31，通过采样接口查看 `prediction`。弯道方向、遮挡、失线、断链及停障的实测都应纳入判断。

S31 默认 `TD_LINE_ASSIST_ENABLED=1`，触屏和网页普通巡线入口使用 15% 低速档。双板使用配套固件并导入经实车验证的模型权重后，满足条件时自动启用辅助。S31 在存在新鲜相机样本时，将模型和当前 CCD 的偏差差值换算成左右履带各最多 5 个百分点的修正，左右加减相抵。C30D 只在 CCD 有效、有效前向测距大于 25 cm、常规巡线及指令未过期时采用，并约束输出在 0–20%。急停、停障、回退和失线仍走原控制代码。普通巡线的前向测距缺失策略沿用原版本。

## 技术要点

- **模仿学习与前馈**。用 C30D 的近场量测作标签，学习相机参考到的前视线形，给既有控制律加前馈。训练采用同一场地的多车次采集，以独立车次验证。
- **边缘推理**。网络参数共 577 个。固件直接做小规模矩阵计算，巡线推理可离线运行。云端 DeepSeek 继续服务于停稳后的作物图像辅助复核。
- **双主控与类 ROS 2 图**。S31 管理界面、视觉及任务，C30D 执行实时运动。协议保留原有两字节巡线帧，启用时才使用三字节扩展帧，第三字节是带符号修正量。
- **可复跑**。运行 `python source/S31/tests/sim/run_simulation.py` 复跑双板控制仿真，运行 `source/C30D/tests/run_host_tests.ps1` 测试底盘巡线。

方法参考：[Ross 等，模仿学习中的序列决策问题](https://proceedings.mlr.press/v15/ross11a.html)。句芒的实现为离线监督学习与有界前馈。
